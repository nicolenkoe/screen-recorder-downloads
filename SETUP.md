# Screen Recorder — сборки и публикация

## Что уже готово в исходниках

Android 0.1.0-experimental, package `ru.screenrecorder.app`, minimum Android 10 (API 29), target API 35. MediaProjection, MediaCodec H.264/AAC, микрофон, AudioPlaybackCapture, громкость микрофона, пауза через уведомление, галерея, VideoView и обрезка копии без изменения исходника. Быстрая обрезка начинает видео со следующего ключевого кадра. Тестовый статус: собран APK и проверена подпись; запись на физическом Android ещё не проверена.

Проверка обновлений при каждом onResume. По умолчанию разрешены prerelease, настройка «Только стабильные версии» выключена. Каталог — GitHub Releases, к каждому релизу прикладывается `update.json`. Проверки APK: размер, SHA-256, packageName, versionCode, подпись текущего приложения. Исправный кеш не загружается снова. «Позже» откладывает предложение на 30 минут, скачивание разрешённых новинок продолжается. Установку подтверждает Android. Stable ниже установленного versionCode не устанавливается как downgrade.

Windows: опубликованы исходники проверенной версии 2.1. Галерея, переработанное оформление и плавающий исключённый индикатор пока не реализованы; не заявлять их как готовые.

## Workflows

- **Build and verify applications**: компиляция Android, 12 тестов выбора релиза, сборка Windows и артефакты. Android-артефакт без подписи — для проверки компиляции, не для установки.
- **Publish signed Android APK**: ручной запуск после добавления секретов подписи. Публикует APK и update.json в GitHub Releases. Канал: experimental, testing или stable.
- **Publish download website**: сайт из `site/` в GitHub Pages. Settings → Pages → Source: GitHub Actions.

## Постоянная подпись Android

Первый APK подписан отдельным ключом, закрытый ключ НЕ находится в этом репозитории. Владельцу передаётся приватная резервная копия.

В Settings → Secrets and variables → Actions добавьте:
- `KEYSTORE_BASE64`: полное содержимое KEYSTORE_BASE64.txt из приватной копии.
- `KEYSTORE_PASSWORD`: содержимое KEYSTORE_PASSWORD.txt.

Alias: `recorder`. Храните копию ключа. Не публикуйте эти файлы, пароль или base64 в issues, README или коммитах. Первый локальный versionCode 10000; CI-публикации используют 20000 + номер запуска публикации.

## Локальная сборка

Установить Android SDK platform 35, build-tools 35.0.0 и JDK 21.

```sh
bash scripts/check.sh
ANDROID_SDK_ROOT=/path/to/sdk bash scripts/build-android.sh
```

Для подписанной сборки задаются `SIGNING_KEYSTORE` и `SIGNING_PASSWORD`. Не выводите пароль в логи.

## Страница и инструкция

На странице первым идёт Android, затем Windows. Инструкция текстовая готова. Видео ещё не снято: `site/tutorial.json` содержит null, поэтому страница явно показывает подготовку ролика. После записи и проверки озвучки нужно положить настоящий ролик и указать URL. Тогда кнопки перейдут к плееру и начнут воспроизведение по нажатию.

## Физическая проверка перед стабильным релизом

Запись 30 секунд: без звука / микрофон / внутренний звук / оба. Разрешения, поворот, системная остановка, пауза, воспроизведение, обрезка и повторный запуск. Обновление с тем же сертификатом и оба режима каналов, повреждённый APK, повторное использование кеша, «Позже», возврат из настроек разрешения установки. Эти проверки на устройстве пока не проведены.
