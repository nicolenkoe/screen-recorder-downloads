# Запись экрана — Android и Windows

[Сайт](https://nicolenkoe.github.io/screen-recorder-downloads/) · [Скачать Android APK](https://nicolenkoe.github.io/screen-recorder-downloads/download.html?platform=android) · [Скачать Windows EXE](https://nicolenkoe.github.io/screen-recorder-downloads/download.html?platform=windows)

На главной кнопки «Скачать» заново выбирают самую новую опубликованную сборку для своей платформы, включая тестовые и экспериментальные. [Список версий](https://nicolenkoe.github.io/screen-recorder-downloads/versions.html) вынесен на отдельную страницу: статусы, даты, фильтр платформы и скачивание конкретного выпуска. Каталог читается из GitHub Releases со всех страниц, черновики исключены.

Android создаётся с нуля: запись экрана, микрофон и внутренний звук, громкость микрофона, пауза через уведомление, галерея, просмотр и быстрая обрезка копии. Android 10+. Это первый экспериментальный APK: сборка и подпись проверены, запись на реальном Android ещё не проверена.

Исходники: `android/`, текущая Windows-версия `windows/`. Android проверяет опубликованные GitHub Releases при каждом возвращении в приложение, по умолчанию включает prerelease. Фильтр «Только стабильные версии» находится в настройках обновлений. Установка требует подтверждения Android.

Windows 3.0.2: новое тёмное оформление с мятными кнопками, компактное меню «Масштаб», область/окно/экран/все мониторы, два независимых ползунка громкости, анимированные схемы режимов, галерея с просмотром и обрезкой отдельной копии. Плавающий индикатор включается только при подтверждённой поддержке исключения из захвата. Для нескольких отдельных окон можно посмотреть схему, но запись этого режима пока недоступна. Пауза записи Windows пока не реализована.

[Видеоинструкция со звуком](https://nicolenkoe.github.io/screen-recorder-downloads/#guide): настоящий интерфейс Windows 3.0.2, женская русская озвучка, красные рамки на элементах управления и субтитры.

## Сборки

[GitHub Actions](https://github.com/nicolenkoe/screen-recorder-downloads/actions): сборка Android/Windows и публикация сайта настроены и проверены. Секреты KEYSTORE_BASE64 и KEYSTORE_PASSWORD работают: подписанный Android-релиз успешно собран и опубликован в Actions. Закрытый ключ и пароль никогда не должны находиться в публичном репозитории.
